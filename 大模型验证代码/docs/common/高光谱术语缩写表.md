# 高光谱术语缩写表

> 本文汇总本项目文档中常见的中英文简称，便于快速查阅。完整说明见各场景学习指南与 [`高光谱训练流程.md`](高光谱训练流程.md)。

## 一、数据采集与格式

| 简称 | 英文全称 | 中文含义 | 在本项目中的用法 |
| --- | --- | --- | --- |
| **DN** | Digital Number | 数字量化值 | 相机直接输出的原始读数，**定标前**使用；常见范围约 0–16383 或 0–65535（uint16） |
| **ROI** | Region of Interest | 感兴趣区域 | 在图像上框选的一块像素区域（如中心 20×20），对其光谱求平均以降低噪声 |
| **ENVI** | Environment for Visualizing Images | ENVI 遥感/高光谱数据格式 | 产线数据常用 `.hdr`（头文件）+ `.dat`（二进制立方体）存储 |
| **H × W × B** | Height × Width × Bands | 高 × 宽 × 波段 | 三维数据立方体的维度，例如 `(480, 640, 224)` |
| **BIP** | Band Interleaved by Pixel | 按像素交错存储 | ENVI 头文件 `interleave = bip` 时，同一像素各波段连续存放 |
| **uint16** | Unsigned 16-bit Integer | 无符号 16 位整数 | ENVI `data type = 12` 对应的数据类型，DN 常用此格式 |
| **nm** | Nanometer | 纳米 | 波长单位，如 `400nm` 表示紫光附近 |
| **HDR** | Header File | 头文件 | ENVI 格式的元数据文件（`.hdr`），记录尺寸、波长、数据类型等 |

### DN 与 ROI 的关系（速查）

```text
相机输出 cube[H, W, B]
  → 在金属表面框选 ROI（如 row 190–210, col 290–310）
  → 对 ROI 内像素求各波段平均 → raw_dn（仍为 DN，未校正）
  → 白板/暗场校正 → reflectance（反射率，0–1）
```

## 二、光谱与成像

| 简称 | 英文全称 | 中文含义 | 在本项目中的用法 |
| --- | --- | --- | --- |
| **VIS** | Visible | 可见光 | 约 400–700nm，人眼可感知波段 |
| **NIR** | Near-Infrared | 近红外 | 约 700–1000nm，人眼不可见，金属质检常用 |
| **VIS-NIR** | Visible to Near-Infrared | 可见光–近红外 | 本项目相机覆盖范围，通常 400–1000nm |
| **D65** | CIE Standard Illuminant D65 | 标准日光光源 | 模拟日光，metadata 中 `illumination: D65` 表示采集光源类型 |

## 三、定标与预处理

| 简称 | 英文全称 | 中文含义 | 在本项目中的用法 |
| --- | --- | --- | --- |
| **暗场** | Dark Reference | 暗电流参考 | 镜头盖关闭时的底噪读数，定标公式中作减项 |
| **白板** | White Reference | 白板参考 | 接近 100% 反射的标准板读数，定标公式中作除项 |
| **SNV** | Standard Normal Variate | 标准正态变量变换 | 散射校正，消除光照/表面粗糙度影响（农业场景常用） |
| **MSC** | Multiplicative Scatter Correction | 乘性散射校正 | 与 SNV 类似的散射校正方法 |

**定标公式（DN → 反射率）：**

```text
反射率 = (原始 DN - 暗场 DN) / (白板 DN - 暗场 DN)
```

## 四、质检与业务

| 简称 | 英文全称 | 中文含义 | 在本项目中的用法 |
| --- | --- | --- | --- |
| **QC** | Quality Control / Quality Check | 质量检查 / 质检 | 样本 ID 前缀 `qc_`、字段 `qc_result` 等均指质检结论 |
| **XRF** | X-Ray Fluorescence | X 射线荧光光谱 | 辅助检测金属纯度/成分，高光谱无法替代时建议联用 |
| **pass / fail / review** | — | 合格 / 不合格 / 待复检 | `qc_result` 字段的常用取值 |

## 五、数据格式与训练

| 简称 | 英文全称 | 中文含义 | 在本项目中的用法 |
| --- | --- | --- | --- |
| **JSON** | JavaScript Object Notation | JSON 数据格式 | 单条光谱样本、标准模板等结构化存储 |
| **JSONL** | JSON Lines | 每行一条 JSON | 千问 SFT 训练文件格式，如 `metal_sft_train.jsonl` |
| **CSV** | Comma-Separated Values | 逗号分隔值 | 标签表、特征导出等，如 `labels.csv` |
| **SFT** | Supervised Fine-Tuning | 有监督微调 | 用标注对话数据微调大模型，使其学会质检输出格式 |
| **LoRA** | Low-Rank Adaptation | 低秩适配 | 低成本微调方式，配置见 `train_lora.yaml` |

## 六、模型与部署

| 简称 | 英文全称 | 中文含义 | 在本项目中的用法 |
| --- | --- | --- | --- |
| **SVM** | Support Vector Machine | 支持向量机 | 传统 baseline 分类器，用于快速验证特征 |
| **PLS-DA** | Partial Least Squares Discriminant Analysis | 偏最小二乘判别分析 | 传统光谱分类方法，低延迟场景可选 |
| **CNN** | Convolutional Neural Network | 卷积神经网络 | 如 1D-CNN，可用于光谱序列分类 |
| **API** | Application Programming Interface | 应用程序接口 | 推理服务对外暴露的 HTTP 接口 |
| **vLLM** | — | 大模型推理框架 | 生产环境高吞吐推理部署选项之一 |

## 七、样本 ID 与字段命名片段

学习指南和示例数据中，常见 ID 片段含义如下：

| 片段 | 含义 | 示例 |
| --- | --- | --- |
| `qc` | 质量检查样本 | `qc_gold_001` |
| `gold` / `silver` | 标称或待检材质 | `qc_gold_001_roi_center` |
| `001` | 样本序号 | 第 1 条 |
| `roi_center` | 中心 ROI 平均光谱 | 取图像中心区域 |
| `raw_` | 原始 DN 阶段 | `raw_qc_gold_001_roi_center` |
