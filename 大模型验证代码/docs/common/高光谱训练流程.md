# 高光谱训练通用流程

本文档整理不同应用场景都会用到的共性流程。无论是金属识别，还是农业/食品质检，整体链路都可以拆成：采集、定标、ROI、特征、训练样本、微调、部署。

## 一、总流程

```text
高光谱相机采集
  → 白板/暗场定标
  → 选择 ROI
  → 提取平均光谱
  → 提取关键波段和组合特征
  → 转成千问训练文本
  → 构建 JSONL
  → LoRA/SFT 微调
  → 推理 API 或业务系统
```

## 三、数据文件如何理解

高光谱数据通常包含三类信息：

| 类型 | 常见字段 | 说明 |
| --- | --- | --- |
| 波长 | `wavelengths_nm` | 每个波段对应的中心波长 |
| 反射率 | `reflectance` | 每个波长位置的反射强度，通常归一化到 0-1 |
| 标签 | `label` | 样本真实类别或业务结论 |
| 元数据 | `metadata` | 相机、光源、定标、ROI、表面状态等采集信息 |

示例：

```json
{
  "wavelengths_nm": [400, 450, 500, 550, 600, 650],
  "reflectance": [0.38, 0.42, 0.55, 0.72, 0.83, 0.88],
  "label": {
    "material_cn": "黄金"
  }
}
```

逐行理解：

- `wavelengths_nm` 表示相机采集了哪些波长点。
- `reflectance` 必须和 `wavelengths_nm` 一一对应。
- 第一个反射率 `0.38` 对应第一个波长 `400nm`。
- 标签 `黄金` 是模型训练时要学习的目标答案。

## 四、ROI 为什么重要

高光谱图像不是一条曲线，而是一个三维数据立方体：

```text
cube.shape = (高度, 宽度, 波段数)
```

例如：

```text
cube.shape = (480, 640, 224)
```

表示：

| 维度 | 含义 |
| --- | --- |
| 480 | 图像高度 |
| 640 | 图像宽度 |
| 224 | 每个像素有 224 个波段 |

为了减少噪声，通常不只取一个像素，而是取一块 ROI：

```python
roi = cube[190:210, 290:310, :]
mean_spectrum = roi.mean(axis=(0, 1))
```

这段代码的含义：

| 代码 | 说明 |
| --- | --- |
| `cube[190:210, 290:310, :]` | 取 20×20 个像素，保留所有波段 |
| `mean(axis=(0, 1))` | 对空间维度求平均 |
| `mean_spectrum` | 得到一条稳定的平均光谱 |

## 五、特征怎么设计

不同场景关注的特征不同。

### 金属识别

| 特征 | 作用 |
| --- | --- |
| `blue_450` | 区分黄金/铜与银/铝 |
| `red_650` | 观察暖色金属红光反射增强 |
| `red_blue_ratio` | 判断红光和蓝光的相对强弱 |
| `slope_450_650` | 判断可见光曲线是否明显上升 |
| `nir_mean_800_1000` | 判断近红外整体反射水平 |
| `surface_state` | 区分抛光、拉丝、氧化、污染等表面状态 |

### 农业/食品质检

| 特征 | 作用 |
| --- | --- |
| `green_peak_550` | 观察绿色峰或表面色素变化 |
| `absorption_680` | 观察叶绿素/变质相关吸收 |
| `red_edge_nm` | 判断红边位置变化 |
| `nir_mean_800_900` | 反映组织结构和水分状态 |
| `water_absorption_960` | 辅助水分相关分析 |

## 六、训练样本怎么写

千问 SFT 常用 JSONL，每一行是一条样本。

```json
{"messages":[{"role":"system","content":"你是一名高光谱金属识别专家。"},{"role":"user","content":"450nm 蓝光反射率：0.42。\n650nm 红光反射率：0.88。\n红蓝比：2.10。"},{"role":"assistant","content":"识别结果：黄金。\n判断依据：蓝光低、红光高、红蓝比高。"}]}
```

三段含义：

| 角色 | 作用 |
| --- | --- |
| `system` | 规定模型身份、任务和回答要求 |
| `user` | 输入高光谱特征 |
| `assistant` | 目标答案，包含结论、依据、建议 |

## 七、训练和部署

训练配置可参考：

[`../configs/train_lora.yaml`](../configs/train_lora.yaml)

常见微调方式：

| 方式 | 说明 |
| --- | --- |
| LoRA | 成本低，适合快速验证 |
| 全参微调 | 成本高，数据量大时再考虑 |
| 传统模型 baseline | 例如 SVM、Random Forest、PLS-DA，可用于快速验证特征是否有效 |

实际项目建议先做一个规则或传统模型 baseline，再做千问微调。千问的优势主要是解释、报告生成和人机交互，不一定是最低延迟的分类器。
