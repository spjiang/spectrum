# 高光谱金属质量检查学习指南：黄金、白银示例

> 本文面向从零学习高光谱的人，重点解释**金属质量检查**场景下：原始数据长什么样、定标后数据长什么样、每一行是什么意思、如何判断合格/不合格、如何把数据变成千问训练样本。

---

## 一、先理解高光谱金属质量检查在做什么

金属质量检查不是单纯“认材料”，而是判断样品是否满足出厂或入库标准，例如：

| 质检项 | 检查内容 | 典型结论 |
| --- | --- | --- |
| 材质符合性 | 标称黄金，实测是否呈现黄金表面光谱 | 合格 / 不合格 / 复检 |
| 表面状态 | 是否抛光良好、是否氧化、是否污染 | A / B / C |
| 替代材料风险 | 是否疑似铜、铝、不锈钢、镀金、镀银 | 高风险 / 中风险 / 低风险 |
| 批次一致性 | 是否与标准合格模板一致 | 放行 / 隔离 / 剔除 |

高光谱相机不是直接给出“合格”二字，而是记录目标表面对不同波长光的反射强度，再由算法或模型结合标准模板做判定。

例如同一束光照到不同金属表面：

| 材料 | 视觉颜色 | 光谱表现的直观理解 |
| --- | --- | --- |
| 黄金 | 黄色 | 蓝紫光反射较低，红光和近红外反射高 |
| 白银 | 银白色 | 可见光到近红外整体反射都很高，曲线较平 |
| 铜 | 红橙色 | 蓝绿光较低，红光和近红外较高 |
| 铝 | 银灰色 | 反射率较高，但通常比银略低，曲线相对平 |
| 氧化金属 | 发暗/发黑/发彩 | 反射率降低，某些波段出现吸收或起伏 |

要注意：高光谱更擅长检查“表面材料或表面状态”，例如黄金色金属表面是否合格、银色金属表面是否异常、是否存在氧化层或镀层风险。若要判断内部纯度，例如 999 足金、925 银、镀金厚度，仅靠普通可见光-近红外高光谱通常不够，工业上常和 XRF、称重密度、导电率等方法结合。

### 质检输出通常包含什么

一条完整的金属质检结果，建议至少包含：

```text
质检结论：合格 / 不合格 / 待复检
合格等级：A / B / C
标称材质：黄金
实测材质：黄金
异常项：无 / 氧化 / 疑似镀金 / 光谱偏离标准模板
判断依据：关键波段说明
处置建议：放行 / 复检 / 隔离 / 剔除
```

## 二、高光谱原始数据长什么样

在讲反射率和质检结论之前，先要理解**相机刚拍出来**的数据。此时还没有 `reflectance` 字段，只有 **DN 值**（Digital Number，数字量化值）和三维数据立方体。更多简称见 [`高光谱术语缩写表.md`](../../common/高光谱术语缩写表.md)。

### 2.1 三维数据立方体

高光谱相机输出的核心是一个 **H × W × B** 的数据立方体：

```text
cube[高度, 宽度, 波段]
```

例如一块标称黄金的饰品扫描图：

```text
cube.shape = (480, 640, 224)
```

| 维度 | 含义 | 本例 |
| --- | --- | --- |
| 480 | 图像行数（高度） | 480 行 |
| 640 | 图像列数（宽度） | 640 列 |
| 224 | 每个像素的光谱波段数 | 224 个波段，约 400–1000nm |

单个像素的一整条原始光谱：

```text
cube[200, 300, :]
```

表示第 200 行、第 300 列这个像素在 224 个波段上的 **原始 DN 值**，还不是反射率。

### 2.2 ENVI 格式与文件结构

产线采集的高光谱数据常以 **ENVI 格式**存储，一个样本通常包含：

```text
data/
├── qc_gold_001.hdr           # 头文件：尺寸、波长、数据类型
├── qc_gold_001.dat           # 二进制立方体：原始 DN
├── qc_gold_001_white.hdr     # 白板参考（定标用）
├── qc_gold_001_white.dat
├── qc_gold_001_dark.hdr      # 暗场参考（定标用）
└── qc_gold_001_dark.dat
```

**qc_gold_001.hdr 示例（节选）：**

```text
ENVI
description = { Gold jewelry QC scan, line 3 }
samples = 640
lines   = 480
bands   = 224
header offset = 0
file type = ENVI Standard
data type = 12
interleave = bip
byte order = 0
wavelength units = Nanometers
wavelength = {
  400.12, 402.85, 405.58, 408.31, 411.04,
  ...（共 224 个波长，单位 nm）
}
```

| 字段 | 含义 |
| --- | --- |
| `samples` | 宽度（列数） |
| `lines` | 高度（行数） |
| `bands` | 波段数 |
| `data type = 12` | uint16，常见 DN 范围约 0–16383 或 0–65535 |
| `interleave = bip` | 按像素交错存储各波段 |

`.dat` 文件本身是二进制数组，不能直接用文本编辑器阅读，需要用 Python、ENVI、或你们的数据处理脚本读取。

### 2.3 原始 DN 值：单像素与 ROI 平均

> **简称速查：** DN = 相机原始数字量化值；ROI = Region of Interest（感兴趣区域）。详见 [`高光谱术语缩写表.md`](../../common/高光谱术语缩写表.md)。

金属表面容易有**镜面高光**和**阴影**，所以质检时通常不只看单个像素，而是取 ROI 内多个像素的平均 DN。

**同一 ROI 内 5 个像素在部分波段上的原始 DN（未校正）：**

```text
像素位置    400nm   450nm   550nm   650nm   850nm   备注
(195,295)   3688    4062    6945    8498    9055    合格黄金 ROI
(196,295)   3620    3998    6860    8420    8980    合格黄金 ROI
(197,296)   3710    4088    6980    8520    9070    合格黄金 ROI
(300,400)   1280    1350    1420    1480    1520    黑色背景/台面
(301,400)   1310    1380    1450    1510    1550    黑色背景/台面
```

读成 Python 数组后：

```python
import numpy as np

# 从 ENVI 读入后，形状 (H, W, Bands)
cube = np.fromfile("qc_gold_001.dat", dtype=np.uint16).reshape(480, 640, 224)

# 取饰品中心 20×20 ROI 的原始 DN
roi = cube[190:210, 290:310, :]
raw_dn_mean = roi.mean(axis=(0, 1))  # shape: (224,)

print(raw_dn_mean[0:5])    # 前 5 个波段的 ROI 平均 DN
print(raw_dn_mean[-5:])    # 后 5 个波段的 ROI 平均 DN
```

| `roi` | 取样区域，与后续 `qc_gold_001_roi_center` 一致 |

### 2.5 从原始 DN 到反射率

原始 DN 不能直接拿来做跨批次比较，必须先做**暗场校正**和**白板校正**：

```text
反射率 = (原始 DN - 暗场 DN) / (白板 DN - 暗场 DN)
```

**以 450nm 波段、合格黄金 ROI 为例：**

```text
原始 DN：     4027
暗场 DN：       52
白板 DN：     9520
反射率 = (4027 - 52) / (9520 - 52) = 3975 / 9468 ≈ 0.42
```

定标后的 0.42，就是下一章样本里 `reflectance` 在 450nm 位置的值。

**Python 定标示例：**

```python
def calibrate_reflectance(raw_dn, dark, white, eps=1e-8):
    numerator = np.asarray(raw_dn, dtype=np.float32) - np.asarray(dark, dtype=np.float32)
    denominator = np.asarray(white, dtype=np.float32) - np.asarray(dark, dtype=np.float32)
    return np.clip(numerator / (denominator + eps), 0, 1)

# 对 ROI 内每个像素、每个波段批量定标
numerator = roi.astype(np.float32) - dark.astype(np.float32)
denominator = white.astype(np.float32) - dark.astype(np.float32)
reflectance_cube = np.clip(numerator / (denominator + 1e-8), 0, 1)
mean_reflectance = reflectance_cube.mean(axis=(0, 1))
```

### 2.6 原始数据与后续章节的关系

完整链路是：

```text
ENVI 原始立方体 (.hdr + .dat)
  → 读取 cube[H, W, B] 和波长表
  → 用白板/暗场做定标
  → 选金属表面 ROI，求平均光谱
  → 得到 reflectance（下一章的 JSON 样本）
  → 提取关键波段特征（第五章）
  → 写成千问训练文本（第六章）
```

所以：**原始数据是起点，反射率样本是定标后的中间结果，训练 JSONL 是最终给模型的输入。**

## 三、一个最小高光谱金属质检样本长什么样

下面是一个简化后的**合格黄金样本**。真实相机可能有 224、256、512 个波段，这里只列 13 个波段，方便学习。

```json
{
  "sample_id": "qc_gold_001_roi_center",
  "material_hint": "标称黄金饰品，产线质检ROI",
  "wavelengths_nm": [400, 450, 500, 550, 600, 650, 700, 750, 800, 850, 900, 950, 1000],
  "reflectance": [0.38, 0.42, 0.55, 0.72, 0.83, 0.88, 0.91, 0.92, 0.93, 0.93, 0.94, 0.94, 0.94],
  "metadata": {
    "camera": "VIS-NIR hyperspectral camera",
    "calibration": "white_reference_corrected",
    "illumination": "D65 simulated light source",
    "roi": "center_20x20_pixels"
  },
  "label": {
    "expected_material": "gold",
    "expected_material_cn": "黄金",
    "detected_material": "gold",
    "detected_material_cn": "黄金",
    "qc_result": "pass",
    "grade": "A",
    "defect": "none",
    "surface_state": "polished",
    "disposition": "release",
    "confidence_label": "expert_verified"
  }
}
```

### 逐行解读

```json
{
```

表示这是一个 JSON 对象。一个对象可以理解成“一条样本记录”。

```json
  "sample_id": "qc_gold_001_roi_center",
```

`sample_id` 是样本编号。质检场景建议命名时包含任务、材质、序号、区域信息。

这里的含义是：

| 片段 | 含义 |
| --- | --- |
| `qc` | 这是质量检查样本 |
| `gold` | 标称或待检材质为黄金 |
| `001` | 第 1 个样本 |
| `roi_center` | 取的是图像中心区域的 ROI 平均光谱 |

ROI 是 Region of Interest（感兴趣区域）。高光谱图像不是只拍一个点，而是拍一整张图。我们通常选中目标上的一个区域，例如中心 20×20 像素，然后把这些像素的光谱取平均，得到一条稳定的光谱曲线。完整简称列表见 [`高光谱术语缩写表.md`](../../common/高光谱术语缩写表.md)。

```json
  "material_hint": "标称黄金饰品，产线质检ROI",
```

`material_hint` 是给人看的备注。它不一定用于训练，也可以保留下来做数据追溯。

这里说明：这条光谱来自一条**标称黄金**的产线质检 ROI。

```json
  "wavelengths_nm": [400, 450, 500, 550, 600, 650, 700, 750, 800, 850, 900, 950, 1000],
```

`wavelengths_nm` 是波长列表，单位是 nm（纳米）。

它告诉我们相机在这些波长位置采集了反射率：

| 波长 | 大致颜色/区域 |
| --- | --- |
| 400nm | 紫光附近 |
| 450nm | 蓝光 |
| 500nm | 蓝绿光 |
| 550nm | 绿光 |
| 600nm | 橙光 |
| 650nm | 红光 |
| 700nm | 红光边缘 |
| 750-1000nm | 近红外，人眼看不见 |

真实高光谱不是只采 13 个点，而是更密集。例如 400 到 1000nm 每隔 2.7nm 采一次，就会有约 224 个波段。

```json
  "reflectance": [0.38, 0.42, 0.55, 0.72, 0.83, 0.88, 0.91, 0.92, 0.93, 0.93, 0.94, 0.94, 0.94],
```

`reflectance` 是反射率列表，必须和 `wavelengths_nm` 一一对应。

第一项 `0.38` 对应 400nm，第二项 `0.42` 对应 450nm，依次类推。

逐项对应关系如下：

| 序号 | 波长 | 反射率 | 解读 |
| --- | --- | --- | --- |
| 1 | 400nm | 0.38 | 黄金对紫光反射偏低 |
| 2 | 450nm | 0.42 | 对蓝光反射仍偏低 |
| 3 | 500nm | 0.55 | 到蓝绿光开始上升 |
| 4 | 550nm | 0.72 | 绿光反射明显升高 |
| 5 | 600nm | 0.83 | 橙光反射高 |
| 6 | 650nm | 0.88 | 红光反射高 |
| 7 | 700nm | 0.91 | 红光边缘反射很高 |
| 8 | 750nm | 0.92 | 近红外保持高反射 |
| 9 | 800nm | 0.93 | 近红外高反射 |
| 10 | 850nm | 0.93 | 近红外高反射 |
| 11 | 900nm | 0.94 | 近红外高反射 |
| 12 | 950nm | 0.94 | 近红外高反射 |
| 13 | 1000nm | 0.94 | 近红外高反射 |

从这条曲线可以看到黄金的一个典型特征：短波段（蓝紫光）较低，长波段（红光、近红外）较高。因此人眼看到黄金是偏黄、偏暖色。

```json
  "metadata": {
```

`metadata` 表示元数据。元数据不是光谱本身，而是关于采集过程的说明。

```json
    "camera": "VIS-NIR hyperspectral camera",
```

`camera` 表示使用的相机类型。`VIS-NIR` 指可见光到近红外，通常覆盖 400-1000nm。

```json
    "calibration": "white_reference_corrected",
```

`calibration` 表示数据已经做过白板校正。

高光谱原始值通常是 DN 值，不是反射率。需要用白板和暗场做校正：

```text
反射率 = (原始值 - 暗场值) / (白板值 - 暗场值)
```

做完这个步骤，不同批次数据才更容易比较。

```json
    "illumination": "D65 simulated light source",
```

`illumination` 表示光源。金属强反光，光源角度和强度对结果影响很大，所以必须记录。

```json
    "roi": "center_20x20_pixels"
```

`roi` 表示取样区域。这里是中心 20×20 像素，即 400 个像素的平均光谱。

```json
  },
```

表示 `metadata` 部分结束。

```json
  "label": {
```

`label` 是质检标签，也就是训练时希望模型学会输出的真值。

```json
    "expected_material": "gold",
    "expected_material_cn": "黄金",
```

标称材质。表示业务上“这应该是什么”，例如订单要求黄金、标签写明白银。

```json
    "detected_material": "gold",
    "detected_material_cn": "黄金",
```

实测材质。表示根据光谱判断“它看起来像什么”。

```json
    "qc_result": "pass",
```

质检结论：

| 值 | 含义 |
| --- | --- |
| `pass` | 合格 |
| `fail` | 不合格 |
| `recheck` | 待复检 |

```json
    "grade": "A",
```

合格等级。常见 A / B / C，也可按你们产线标准自定义。

```json
    "defect": "none",
```

缺陷类型。例如 `none`、`oxidation`、`contamination`、`plating_risk`、`spectral_deviation`。

```json
    "surface_state": "polished",
```

表面状态。质检中非常关键，抛光、拉丝、氧化、污渍、镀层都会改变光谱，也会直接影响是否合格。

```json
    "disposition": "release",
```

处置建议：

| 值 | 含义 |
| --- | --- |
| `release` | 放行 |
| `recheck` | 复检 |
| `quarantine` | 隔离 |
| `reject` | 剔除 |

```json
    "confidence_label": "expert_verified"
```

标签可信度。`expert_verified` 表示由专家或可靠仪器确认过。

```json
  }
}
```

表示标签结束，整条样本结束。

## 四、合格与不合格金属的光谱差异

下面是便于学习的示例。数值是教学用的简化反射率，不等同于某台真实设备的标定数据。质检时重点不是只认材料，而是看**是否偏离合格模板**。

| 材料/状态 | 400nm | 450nm | 500nm | 550nm | 600nm | 650nm | 700nm | 800nm | 900nm | 质检含义 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 合格黄金 | 0.38 | 0.42 | 0.55 | 0.72 | 0.83 | 0.88 | 0.91 | 0.93 | 0.94 | 标称黄金且表面正常，可放行 |
| 合格白银 | 0.88 | 0.90 | 0.91 | 0.92 | 0.93 | 0.93 | 0.94 | 0.94 | 0.95 | 标称白银且表面正常，可放行 |
| 疑似铜替代 | 0.32 | 0.36 | 0.48 | 0.61 | 0.72 | 0.80 | 0.85 | 0.88 | 0.90 | 标称黄金但光谱偏铜色，建议复检 |
| 氧化金属 | 0.22 | 0.24 | 0.28 | 0.31 | 0.33 | 0.35 | 0.36 | 0.38 | 0.39 | 近红外整体偏低，表面不合格 |

### 如何读这张表

质检时建议同时看三件事：

1. **标称材质是什么**
2. **实测光谱像什么**
3. **是否偏离合格模板**

例如标称黄金：

```text
450nm=0.42，650nm=0.88，红蓝比≈2.10，近红外均值>0.90 → 合格黄金
```

如果标称黄金，但测出来：

```text
450nm=0.36，650nm=0.80，红蓝比≈2.22，近红外均值≈0.89 → 更像铜色金属，建议复检
```

如果近红外整体明显降低：

```text
800-1000nm 均值 < 0.45 → 可能存在氧化、污染或表面异常，判定不合格
```

## 五、从原始光谱到质检特征

训练千问时，不建议把一整串 224 个反射率全部直接塞进去。更推荐先提取容易理解的特征，再让千问学习“特征 → 质检结论 → 判断依据 → 处置建议”。

### 5.1 示例：合格黄金质检特征

```json
{
  "sample_id": "qc_gold_001_roi_center",
```

### 特征逐行解读

```json
  "blue_450": 0.42,
```

450nm 蓝光反射率为 0.42。黄金对蓝光吸收较强，所以蓝光反射偏低。

```json
  "green_550": 0.72,
```

550nm 绿光反射率为 0.72，比 450nm 高很多，说明曲线在可见光中段开始上升。

```json
  "red_650": 0.88,
```

650nm 红光反射率为 0.88。黄金对红光反射高，这是它呈现金黄色的重要原因。

```json
  "nir_850": 0.93,
```

850nm 近红外反射率为 0.93。很多光亮金属在近红外都有高反射。

```json
  "slope_450_650": 0.0023,
```

从 450nm 到 650nm 的上升斜率。

计算方式大致是：

```text
slope_450_650 = (red_650 - blue_450) / (650 - 450)
              = (0.88 - 0.42) / 200
              = 0.0023
```

这个值越大，说明从蓝光到红光上升越明显。黄金、铜通常比银、铝更明显。

```json
  "red_blue_ratio": 2.10,
```

红蓝比值：

```text
red_blue_ratio = red_650 / blue_450
               = 0.88 / 0.42
               = 2.10
```

黄金的红蓝比通常较高，因为红光反射强、蓝光反射弱。白银的红蓝比接近 1，因为它各波段都很高且比较平。

```json
  "nir_mean_800_1000": 0.936,
```

800-1000nm 近红外区间的平均反射率。黄金样本在近红外很高，均值接近 0.94。

```json
  "expected_material": "黄金",
```

标称材质。质检时要先知道“它应该是什么”。

```json
  "qc_result": "pass",
  "grade": "A",
```

质检结论和等级。模型最终要学会输出这类业务结果，而不只是材料名称。

## 六、金属质检训练数据 JSONL 是什么

大模型微调常用 JSONL。JSONL 的意思是：一个文件里每一行都是一条完整 JSON。

例如 `metal_sft_train.jsonl` 的第一行可以是：

```json
{"messages":[{"role":"system","content":"你是一名高光谱金属质检专家，请根据反射率特征判断样品是否合格，并说明依据和处置建议。"},{"role":"user","content":"样本编号：qc_gold_001_roi_center。\n标称材质：黄金。\n采集范围：400-1000nm。\n450nm 蓝光反射率：0.42。\n550nm 绿光反射率：0.72。\n650nm 红光反射率：0.88。\n850nm 近红外反射率：0.93。\n450-650nm 上升斜率：0.0023。\n红蓝比：2.10。\n800-1000nm 近红外均值：0.936。\n表面状态：抛光。\n标准模板：红蓝比 1.9-2.3，近红外均值 > 0.90。"},{"role":"assistant","content":"质检结论：合格。\n合格等级：A。\n标称材质：黄金。\n实测材质：黄金。\n置信度：高。\n判断依据：\n1. 蓝光反射率较低（450nm=0.42），红光反射率较高（650nm=0.88），符合黄金表面光谱；\n2. 红蓝比 2.10，落在标准模板 1.9-2.3 范围内；\n3. 近红外均值 0.936，高于合格阈值 0.90，表面反射稳定。\n处置建议：放行。"}]}
```

### 逐段解读

```json
{"messages":[
```

表示这一行是一条训练样本，里面包含多轮对话。千问微调时，会学习这种“用户输入 → 助手输出”的格式。

```json
{"role":"system","content":"你是一名高光谱金属质检专家，请根据反射率特征判断样品是否合格，并说明依据和处置建议。"}
```

`system` 是系统角色，用于规定模型身份和回答风格。

这句话的作用是告诉模型：

| 内容 | 含义 |
| --- | --- |
| 高光谱金属质检专家 | 模型要扮演质检员，而不是普通分类器 |
| 根据反射率特征 | 不要凭空猜，要看光谱数据和标准模板 |
| 判断样品是否合格 | 输出合格 / 不合格 / 待复检 |
| 说明依据和处置建议 | 要解释关键波段，并给出放行、复检、剔除建议 |

```json
{"role":"user","content":"样本编号：metal_gold_001_roi_center。\n采集范围：400-1000nm。\n450nm 蓝光反射率：0.42。\n..."}
```

`user` 是用户输入，也就是实际推理时你会给模型的数据。

逐行解释 `content`：

```text
样本编号：metal_gold_001_roi_center。
```

告诉模型这是哪一个样本，方便结果追溯。

```text
标称材质：黄金。
```

告诉模型这条样品的业务要求是什么。质检一定是“拿实测结果去对标称要求”。

```text
标准模板：红蓝比 1.9-2.3，近红外均值 > 0.90。
```

合格判定不能只看像不像黄金，还要看是否落在你们定义的合格范围内。

```text
450nm 蓝光反射率：0.42。
```

蓝光反射率。黄金和铜一般偏低，银和铝通常偏高。

```text
550nm 绿光反射率：0.72。
```

绿光反射率。用于观察从蓝光到绿光是否明显上升。

```text
650nm 红光反射率：0.88。
```

红光反射率。黄金和铜在红光区反射明显增强。

```text
850nm 近红外反射率：0.93。
```

近红外反射率。用于判断金属表面整体高反射特性，也可辅助区分氧化、污染或暗色表面。

```text
450-650nm 上升斜率：0.0023。
```

用一个数字概括蓝光到红光的上升速度。黄金、铜通常上升斜率较明显，银、铝较平。

```text
红蓝比：2.10。
```

650nm / 450nm。这个值越高，越说明“红光强、蓝光弱”，越接近黄金或铜色特征。

```text
800-1000nm 近红外均值：0.936。
```

近红外整体反射水平。高且稳定通常说明是光亮金属表面。

```text
表面状态：抛光。
```

表面状态必须写清楚。抛光金属、磨砂金属、氧化金属的光谱差异可能很大。

```json
{"role":"assistant","content":"质检结论：合格。\n合格等级：A。\n标称材质：黄金。\n实测材质：黄金。\n置信度：高。\n判断依据：..."}
```

`assistant` 是希望模型学会输出的答案。

逐行解释：

```text
质检结论：合格。
```

这是最终业务结论，比“识别为黄金”更重要。

```text
合格等级：A。
```

表示不仅合格，而且质量等级较高。

```text
标称材质：黄金。
实测材质：黄金。
```

质检必须同时输出“要求是什么”和“测出来像什么”。

```text
置信度：高。
```

模型根据特征给出的可信程度。

```text
判断依据：
```

后面必须写依据。质检不能只输出“合格/不合格”，还要解释为什么。

```text
处置建议：放行。
```

处置建议是质检闭环的一部分，例如：

| 处置 | 含义 |
| --- | --- |
| 放行 | 进入下一工序或出货 |
| 复检 | 转人工或 XRF 复检 |
| 隔离 | 暂存，不得混批 |
| 剔除 | 不合格品下线 |

## 八、从头到尾的质检学习路线

### 第一步：读取原始 ENVI 数据

相机输出的是 ENVI 格式的三维立方体，详见**第二章**。先用脚本读入 `cube[H, W, B]`、波长表，以及白板/暗场参考。

### 第二步：白板定标，得到反射率

定标公式：`反射率 = (raw - dark) / (white - dark)`。定标后每个像素、每个波段才是 0~1 的反射率。

例如：

```text
cube.shape = (480, 640, 224)
```

意思是：

| 维度 | 含义 |
| --- | --- |
| 480 | 图像有 480 行 |
| 640 | 图像有 640 列 |
| 224 | 每个像素有 224 个波段 |

### 第三步：选 ROI

金属表面容易有高光、阴影、划痕，所以不要只取单个像素。建议选一块稳定区域：

```text
roi = cube[190:210, 290:310, :]
```

含义：

| 片段 | 含义 |
| --- | --- |
| `190:210` | 取第 190 到 209 行 |
| `290:310` | 取第 290 到 309 列 |
| `:` | 取所有波段 |

这个 ROI 一共有 20×20=400 个像素。

### 第四步：算平均光谱

```python
mean_spectrum = roi.mean(axis=(0, 1))
```

逐段解释：

| 代码 | 含义 |
| --- | --- |
| `roi` | 20×20×224 的小立方体 |
| `.mean(...)` | 求平均 |
| `axis=(0, 1)` | 沿着行和列求平均 |
| 结果 | 得到 224 个数，也就是一条平均光谱 |

### 第五步：提取关键波段

```python
blue_450 = value_at(mean_spectrum, wavelengths, 450)
green_550 = value_at(mean_spectrum, wavelengths, 550)
red_650 = value_at(mean_spectrum, wavelengths, 650)
nir_850 = value_at(mean_spectrum, wavelengths, 850)
```

这些波段的作用：

| 特征 | 作用 |
| --- | --- |
| `blue_450` | 区分银白金属和黄金/铜色金属 |
| `green_550` | 观察中段是否开始上升 |
| `red_650` | 黄金、铜在这里通常较高 |
| `nir_850` | 判断整体金属反射与表面状态 |

### 第六步：计算组合特征

```python
slope_450_650 = (red_650 - blue_450) / 200
red_blue_ratio = red_650 / blue_450
```

逐行解释：

```python
slope_450_650 = (red_650 - blue_450) / 200
```

650nm 和 450nm 相差 200nm。用反射率差除以波长差，就得到上升斜率。

```python
red_blue_ratio = red_650 / blue_450
```

红蓝比用于判断颜色倾向：

| 红蓝比 | 可能材料 |
| --- | --- |
| 接近 1 | 白银、铝、不锈钢等银白金属 |
| 明显大于 1 | 黄金、铜等暖色金属 |

### 第七步：转成训练输入

把数值变成容易理解的文本：

```text
样本编号：qc_gold_001_roi_center。
标称材质：黄金。
采集范围：400-1000nm。
450nm 蓝光反射率：0.42。
550nm 绿光反射率：0.72。
650nm 红光反射率：0.88。
850nm 近红外反射率：0.93。
450-650nm 上升斜率：0.0023。
红蓝比：2.10。
800-1000nm 近红外均值：0.936。
表面状态：抛光。
标准模板：红蓝比 1.9-2.3，近红外均值 > 0.90。
```

为什么要这样写？

| 文本行 | 训练意义 |
| --- | --- |
| 样本编号 | 方便追踪数据 |
| 标称材质 | 明确质检对象和要求 |
| 采集范围 | 说明波段上下文 |
| 450/550/650/850nm | 给出关键观测点 |
| 上升斜率 | 概括曲线形状 |
| 红蓝比 | 判断是否偏离合格模板 |
| 近红外均值 | 判断表面是否异常 |
| 表面状态 | 避免抛光/氧化混淆 |
| 标准模板 | 让模型学习“合格范围”而不是死记材料名 |

### 第八步：让模型学习输出

模型要学习的不只是材料分类，而是完整质检报告：

```text
质检结论：合格。
合格等级：A。
标称材质：黄金。
实测材质：黄金。
判断依据：
1. 红蓝比落在标准模板内；
2. 近红外均值高于阈值；
3. 表面状态正常。
处置建议：放行。
```

这样训练出来的模型更适合业务应用，因为它能给出可读报告，而不是只返回一个类别编号。

## 九、金属质检项目的采集建议

为了让质检模型真的可用，采集数据时要控制变量。

| 采集项 | 建议 |
| --- | --- |
| 光源 | 固定光源型号、亮度、角度 |
| 相机角度 | 固定相机和样品夹角，避免镜面反射过曝 |
| 白板校正 | 每批采集前做白板/暗场校正 |
| 标称材质 | 每条样本必须记录标称黄金/白银/合金 |
| 合格模板 | 为每种材质建立 A/B/C 级标准阈值 |
| 表面状态 | 分开采集抛光、拉丝、氧化、污渍、镀层 |
| 不合格样本 | 必须加入替代材料、氧化、污染、镀层风险样本 |
| 标签确认 | 贵金属建议用 XRF 或权威检测作为标签来源 |

## 十、一个实用质检规则示例

在没有训练模型前，可以先做规则 baseline：

```text
如果标称黄金，红蓝比在标准模板内，且近红外均值 > 0.90 → 合格
如果标称黄金，但光谱更像铜色金属 → 待复检
如果标称白银，但近红外均值 < 0.60 → 不合格，疑似氧化
如果标称与实测差异大 → 隔离，不得放行
```

示例规则：

```python
def inspect_metal_qc(expected_material, blue_450, red_650, nir_mean):
    red_blue_ratio = red_650 / max(blue_450, 1e-6)

    if expected_material == "gold":
        if 1.9 <= red_blue_ratio <= 2.3 and nir_mean > 0.90:
            return "合格，放行"
        if red_blue_ratio > 1.8 and nir_mean < 0.90:
            return "待复检，疑似替代材料"
        return "不合格，隔离"

    if expected_material == "silver":
        if 0.98 <= red_blue_ratio <= 1.08 and nir_mean > 0.92:
            return "合格，放行"
        if nir_mean < 0.60:
            return "不合格，疑似氧化"
        return "待复检"

    return "未知标称材质，需补充标准模板"
```

这段规则不是最终方案，但适合用来理解模型为什么需要这些特征。

## 十一、学习总结

金属高光谱**质量检查**的核心学习路径是：

```text
ENVI 原始立方体
  → 白板/暗场定标
  → 选金属表面 ROI
  → 得到平均光谱曲线
  → 提取关键波段和组合特征
  → 对比标称材质和标准模板
  → 写成质检训练文本
  → 千问学习“特征 → 质检结论 → 依据 → 处置建议”
```

对黄金和白银质检来说，最容易先理解的区别是：

| 对比项 | 合格黄金 | 合格白银 |
| --- | --- | --- |
| 质检目标 | 标称黄金且光谱符合模板 | 标称白银且光谱符合模板 |
| 蓝光 450nm | 较低 | 很高 |
| 红光 650nm | 很高 | 很高 |
| 红蓝比 | 明显大于 1 | 接近 1 |
| 常见不合格原因 | 疑似铜替代、镀层风险 | 氧化、镀银混淆、污染 |
| 典型处置 | 放行 / 复检 / 隔离 | 放行 / 剔除 / 复检 |

所以实际质检项目中，不能只采“合格黄金”和“合格白银”，还必须加入：

- 不合格样本：氧化、污染、表面损伤
- 风险样本：铜、铝、不锈钢、镀金、镀银
- 边界样本：接近阈值、需人工复检的样本
