## 二、原始数据格式说明

### 2.1 三维数据立方体

高光谱相机的核心输出是一个 **H × W × B** 的数据立方体：

```
H = 图像高度（行数，如 480）
W = 图像宽度（列数，如 640）
B = 光谱波段数（如 224）
```

每个像素 `(row, col)` 对应一条长度为 B 的光谱曲线。

### 2.2 ENVI 格式示例

**文件结构：**

```
data/
├── sample_001.hdr      # 头文件（元数据）
├── sample_001.dat      # 二进制光谱数据
├── sample_001_white.hdr  # 白板参考（定标用）
└── sample_001_dark.hdr   # 暗电流参考（定标用）
```

## 三、数据预处理流水线

### 3.1 完整流程图

```
原始 DN 值
    │
    ▼
① 暗电流校正    raw - dark
    │
    ▼
② 白板校正      (raw - dark) / (white - dark)  →  反射率 [0, 1]
    │
    ▼
③ 坏波段剔除    去除饱和/噪声波段
    │
    ▼
④ 光谱平滑      Savitzky-Golay 滤波
    │
    ▼
⑤ 散射校正      SNV 或 MSC（消除光照/表面粗糙度影响）
    │
    ▼
⑥ ROI 提取      按标签区域取平均光谱或保留像素级数据
    │
    ▼
⑦ 特征工程      红边、吸收谷、波段比值、PCA 等
    │
    ▼
⑧ 文本化        转成自然语言描述 → 写入训练 JSONL
```

### 3.2 定标公式示例

```python
def calibrate_reflectance(raw, dark, white, eps=1e-8):
    """
    raw/dark/white: 同尺寸的 (H, W, B) 数组
    返回反射率，范围约 0~1
    """
    numerator = raw.astype(np.float32) - dark.astype(np.float32)
    denominator = white.astype(np.float32) - dark.astype(np.float32)
    reflectance = numerator / (denominator + eps)
    return np.clip(reflectance, 0, 1)
```

**定标前后对比（单像素）：**

```text
波段 550nm:
  原始 DN 值:     1842
  暗电流:          52
  白板:          9650
  反射率 = (1842-52)/(9650-52) = 0.186

定标后该像素 550nm 反射率: 0.186
```

### 3.3 SNV 散射校正示例

```python
def snv(spectrum):
    """对单条光谱做 Standard Normal Variate 校正"""
    return (spectrum - spectrum.mean()) / (spectrum.std() + 1e-8)

# 校正前: [0.05, 0.06, 0.12, 0.03, 0.45, 0.52, ...]
# 校正后: [-1.12, -1.05, -0.32, -1.28,  0.85,  1.21, ...]
```

### 3.4 光谱特征提取示例

```python
def extract_spectral_features(spectrum, wavelengths):
    """从一条光谱中提取业务相关特征"""
    # 找 680nm 附近吸收谷（叶绿素）
    idx_680 = np.argmin(np.abs(wavelengths - 680))
    absorption_680 = spectrum[idx_680]

    # 红边位置：700~750nm 最大一阶导数处
    idx_range = (wavelengths >= 700) & (wavelengths <= 750)
    derivative = np.gradient(spectrum[idx_range])
    red_edge_nm = wavelengths[idx_range][np.argmax(derivative)]

    # 近红外平台均值 800~900nm
    idx_nir = (wavelengths >= 800) & (wavelengths <= 900)
    nir_mean = spectrum[idx_nir].mean()

    # 绿峰 550nm
    idx_550 = np.argmin(np.abs(wavelengths - 550))
    green_peak = spectrum[idx_550]

    return {
        "absorption_680": round(float(absorption_680), 4),
        "red_edge_nm": round(float(red_edge_nm), 1),
        "nir_mean_800_900": round(float(nir_mean), 4),
        "green_peak_550": round(float(green_peak), 4),
    }
```

**输出示例：**

```json
{
  "absorption_680": 0.0342,
  "red_edge_nm": 718.5,
  "nir_mean_800_900": 0.4512,
  "green_peak_550": 0.1183
}
```

**伪彩色合成代码：**

```python
def make_false_color_rgb(cube, wavelengths):
    """选三个波段合成 RGB 伪彩色图"""
    def nearest_band(target_nm):
        return np.argmin(np.abs(wavelengths - target_nm))

    r = cube[:, :, nearest_band(650)]
    g = cube[:, :, nearest_band(550)]
    b = cube[:, :, nearest_band(450)]
    rgb = np.stack([r, g, b], axis=-1)

    # 归一化到 0-255
    rgb = (rgb - rgb.min()) / (rgb.max() - rgb.min() + 1e-8)
    return (rgb * 255).astype(np.uint8)
```

### 5.4 超参数调优参考

| 参数 | 起步值 | 调优方向 |
|------|--------|----------|
| learning_rate | 1e-4 ~ 2e-4 | loss 不降则减小，收敛慢则略增 |
| lora_rank | 8 / 16 / 32 | 任务复杂度高时用 32~64 |
| num_epochs | 3 | 过拟合则减到 1~2，欠拟合则增到 5 |

from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel

base_model = "Qwen/Qwen2.5-7B-Instruct"
lora_path = "saves/spectrum-qwen-lora"

tokenizer = AutoTokenizer.from_pretrained(base_model, trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(
    base_model, torch_dtype="auto", device_map="auto", trust_remote_code=True
)
model = PeftModel.from_pretrained(model, lora_path)

user_input = """样本编号：APPLE-NEW-001。

样本类型：苹果。"""

    {"role": "system", "content": "你是一名高光谱农产品质检专家，请根据光谱特征判断样本状态，并给出简要依据。"},
    {"role": "user", "content": user_input},
]

text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
inputs = tokenizer(text, return_tensors="pt").to(model.device)

## 九、常见问题

### Q1：为什么不直接把 224 维光谱数组喂给千问？

千问是语言模型，输入是 token 序列。224 个浮点数既占 token 又缺乏语义。应先提取有物理意义的特征（红边、吸收谷等），再转成自然语言，效果更好、成本更低。

### Q2：需要多少 GPU？

| 配置 | 显存 | 可训练模型 |
|------|------|-----------|
| 单卡 RTX 4090 | 24GB | Qwen2.5-7B LoRA |
| 单卡 A100 40GB | 40GB | Qwen2.5-14B LoRA |
| 2×A100 80GB | 160GB | Qwen2.5-72B LoRA |

### Q3：传统 ML 和千问怎么选？

| 场景 | 推荐 |
|------|------|
| 只要分类结果、要求极低延迟 | PLS-DA / 1D-CNN |
| 要自然语言报告、可解释性 | Qwen 微调 |
| 产线 < 100ms 响应 | 传统 ML 做判定 + Qwen 异步出报告 |
| 多模态（看缺陷图） | Qwen-VL |

### Q4：没有化学真值能做糖度预测吗？

不能。回归任务必须有实验室标定的糖度/水分真值。可以先用分类任务（好/坏）启动项目。
