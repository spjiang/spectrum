# LUMIR Spectral Agent — 整体说明

本 Skill（`lumir-spectral-agent`）把中山大学 LUMIR（LLM-driven Unified agent for Multi-task Infrared spectroscopy Reasoning）论文流水线工程化为**可自包含分发**的 Cursor / OpenClaw Skill：内嵌知识库，对**用户上传或用户给出路径**的光谱跑端到端；无密钥时可跑离线作业。

- **Agent 生产规程入口**：[SKILL.md](SKILL.md)
- **本文作用**：总览「是什么、目录干什么、谁在跑、文档怎么查」
- **便携分发**：[PORTABLE.md](PORTABLE.md)

---

## 1. 它做什么

对齐论文五步流水线：

```text
1. LLM 实体抽取（研究对象 + 任务类型）
2. BM25 检索结构化文献知识库 → 预处理 / 特征方法描述
3. LLM 将文献方法名映射为代码函数名，再多数投票（可跳过）
4. 本地化学计量学：预处理 + 特征提取（不调 LLM）
5. LLM few-shot：分类 / 回归 / 异常检测（只吃低维特征，不吃原始高维光谱）
```

约束原则：**禁止把完整原始高维光谱直接塞给 LLM。作业光谱必须来自用户文件路径。**

## 2. 两层结构

| 层级 | 路径 | 是否参与默认运行 | 作用 |
|------|------|------------------|------|
| 工程层 | `scripts/` + `knowledge_base/` + 配置 | **是** | 生产作业、E2E、报告输出 |
| 对照层 | `vendor/LLM-Agent-for-Automated-Infrared-Spectral-Reasoning-main/` | **否** | 论文原仓库源码副本 |
| 溯源层 | `Papers/` | 否（E2E 不读） | 结构化库里 `paper_url` 对应的 md / 元数据 |
| 产出层 | `runs/` | 写出 | `e2e_*.json` / `offline_*.json` |

删掉 `vendor/` 或 `Papers/` **不影响** `run_offline` / `run_e2e`；删掉 `knowledge_base/` 或用户未提供 `--data` 则会失败。

## 4. 各目录详细作用

### 4.1 `scripts/`

| 文件 | 作用 | 是否需要 API Key |
|------|------|------------------|
| `run_offline.py` | 检索 + Table4 方法 + 本地预处理特征；`--offline` 不调 LLM | 否 |
| `run_e2e.py` | 五步 E2E；`--skip-method-llm`、`--stop-after` | 完整跑：是 |
| `job_input.py` | `--data` / `--label` 校验 | — |

### 4.2 `knowledge_base/`

- BM25 按「研究对象」检索，返回文献中的预处理 / 特征方法描述。
- `primary: auto` 时自动用内嵌 `structured_papers1.json`。

### 4.3 用户数据

生产作业**不读取** Skill 内样本目录作为默认输入。必须：

- OpenClaw / 对话中上传的文件绝对路径；或
- `--data` / `--label` 指向的本机路径（`.npy`）

### 4.4 `Papers/` / `vendor/` / `runs/`

- `Papers/`：人工核对原文；脚本运行时不读。
- `vendor/`：对照实现，不是入口。
- `runs/`：JSON 报告（含 `data_path`）。

## 6. 快速上手

```bash
cd .cursor/skills/lumir-spectral-agent
pip install -r requirements.txt

python scripts/run_offline.py \
  --data /path/to/spectra.npy --task classification --object "your material" --offline

cp .env.example .env          # 填写 LUMIR_API_KEY
cp config.example.yaml config.yaml
python scripts/run_e2e.py \
  --data /path/to/spectra.npy --task classification --object "your material"
```
