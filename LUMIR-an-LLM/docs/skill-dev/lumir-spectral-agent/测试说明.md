# LUMIR 作业与验收说明

面向生产验收：讲什么、跑哪条命令、屏幕上会出现什么。配置见 [配置说明.md](配置说明.md)。

---

## 一、一句话说明

> LUMIR 用大模型当调度层：先读懂光谱分析意图，再检索文献知识库选预处理/特征方法，本地算特征，最后用少量示例做分类或回归——**不把原始高维光谱整段塞进大模型**。光谱必须由用户上传或给出路径。

默认模型：**DeepSeek**（`deepseek-chat`）。

## 三、建议验收节奏

| 时段 | 内容 | 命令 |
|------|------|------|
| 输入确认 | 路径存在、任务类型明确 | 不跑模型 |
| 五步说明 | 对照流程图 | 不跑 |
| 离线作业 | 检索 + 特征 + 本地对照 | 作业 A |
| 完整链路 | 实体 → 检索 → 方法 → 特征 → LLM 推理 | 作业 B |
| 回归 | 连续含量 | 作业 C |
| 报告 | 打开 `runs/*.json` | 收尾 |

## 四、五步（对照屏幕输出）

```text
用户光谱路径 + 自然语言问题
        │
        ▼
[1] LLM 实体抽取     → 研究对象、任务类型
        ▼
[2] BM25 查知识库    → 预处理 / 特征描述
        ▼
[3] LLM 方法映射     → 代码函数名，再投票
        ▼
[4] 本地化学计量学   → 低维特征
        ▼
[5] LLM few-shot     → 类别或连续数值
```

- **知识库**是结构化 JSON，不必打开 `Papers/md` 全文
- **步骤 2、4 不是 LLM**；LLM 主要在 1 / 3 / 5
- 给人看的是**标签或指标**，不是原始光谱向量

## 五、现场命令

### 作业 A：离线（不耗 API）

```bash
python $SKILL/scripts/run_offline.py \
  --data "$SPECTRA" --task classification --object "<材料名>" --offline
```

屏幕应出现：研究对象、BM25 命中、选定方法、特征 shape、本地基线 Acc 或 R²、`runs/offline_*.json`。

### 作业 B：完整 E2E（分类）

```bash
python $SKILL/scripts/run_e2e.py \
  --data "$SPECTRA" --task classification --object "<材料名>"
```

| 输出段 | 含义 |
|--------|------|
| `[1] LLM 实体抽取` | 研究对象与任务 |
| `[2] BM25 知识库检索` | 结构化文献命中 |
| `[3] 方法映射` | 文献说法 → 可执行函数 |
| `[4] 预处理 + 特征` | 高维光谱 → 低维特征 |
| `[5] LLM few-shot` | Acc 等指标 |
| `报告已写入 runs/...` | 归档 |

```bash
python $SKILL/scripts/run_e2e.py --data "$SPECTRA" --task classification --object "<材料名>" --stop-after retrieve
python $SKILL/scripts/run_e2e.py --data "$SPECTRA" --task classification --object "<材料名>" --stop-after features
```

### 作业 C：回归

```bash
python $SKILL/scripts/run_e2e.py \
  --data "$SPECTRA" --label "$LABELS" --task regression --object "<材料名>"
```

期望：`task_type=regression`，指标含 R² / RMSE。

排障：加 `--skip-method-llm`。

## 七、Q&A

| 提问 | 回答 |
|------|------|
| 数据从哪来？ | 用户上传或 `--data` 路径，没有默认样本作业 |
| 必须自建知识库吗？ | 先用现成 `structured_papers1.json` |
| Papers 要同步吗？ | 不用；流水线读 JSON 字段 |
| API 不可用？ | 改离线作业 + 历史 `runs` 报告 |
