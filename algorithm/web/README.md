# 高光谱算法可视化控制台

给领导看业务链路、给研发调接口的独立前端。开发地址 **http://127.0.0.1:5173**，通过 Vite 代理访问算法服务 **28800**。

## 启动（两个进程）

```bash
# 1. 算法服务
cd algorithm/source
./scripts/start.sh

# 2. 控制台
cd algorithm/web
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173 。不要把磁盘绝对路径当图片地址；预览一律走 `/api/v1/console/`。

## 能力

- 首页：九段产线（与左侧菜单同名，可点进入算法）
- 左栏：全流程 + 45 项按九段分组
- 算法页：介绍、场景、字段表、一键 testdata、上传自有 file/file2
- 栅格：假彩色 / 指数色带 / 分类色块；多波段可点图像看光谱
- 航线/地块：Leaflet 地图；POS：轨迹 + 高度曲线
