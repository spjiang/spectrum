# 常用植被指数 18 项对照

对照外部产品「常用植被指数」目录（NDVI、RECI、NDRE 等 **18** 个）与本仓库 **55** 项算法清单。

两套清单不是一回事：

- 外部这 18 个：几乎全是 **L3 光谱指数**（少数把 LAI 也放进指数菜单）
- 本仓库 55 项：从航线、定标、正射到分类、地块报表的 **整条产线**；指数只占其中一段

统计（按「有没有做成同名指数产品」）：

| | 个数 | 指数 |
| --- | --- | --- |
| **已做** | **18** | NDVI、RECI、NDRE、MSAVI、GNDVI、NDWI、MNDWI、NDMI、SAVI、OSAVI、ARVI、EVI、VARI、LAI（指数口径）、NBR、SIPI、GCI、NDSI |
| **没做** | **0** | — |

已做的 18 个不是 18 个独立接口：NDVI、NDRE 各一项；EVI/SAVI/MSAVI 捆在 `#29`；NDMI/NDWI/MNDWI 捆在 `#30`；其余 10 个为 `#46`–`#55` 独立项。

## 已做接口

控制台路径：`/algo/27_ndvi`、`/algo/28_ndre`、`/algo/29_evi_savi`、`/algo/30_ndmi_ndwi`，以及 `/algo/46_reci` … `/algo/55_ndsi`。  
输入均要求 **反射率** GeoTIFF，波段索引从 0 起（教学数据默认：蓝 0、绿 1、红 2、近红外 3、红边 4、SWIR 5）。

| 简称 | 接口 | 公式（本仓库实现） | 说明 |
| --- | --- | --- | --- |
| NDVI | `POST /api/v1/27_ndvi/run` | `(NIR − RED) / (NIR + RED)` | 最常用绿度/长势 |
| RECI | `POST /api/v1/46_reci/run` | `NIR/RE − 1` | 须真红边；值域不是 −1～1 |
| NDRE | `POST /api/v1/28_ndre/run` | `(NIR − RE) / (NIR + RE)` | 密冠层、氮营养；须有真红边 |
| EVI | `#29` 的 `evi.tif` | `2.5(NIR−RED)/(NIR+6RED−7.5BLUE+1)` | 抑饱和、含蓝光项 |
| SAVI | `#29` 的 `savi.tif` | `(1+L)(NIR−RED)/(NIR+RED+L)`，默认 `L=0.5` | 稀疏植被压土壤 |
| MSAVI | `#29` 的 `msavi.tif` | `0.5[2NIR+1−√((2NIR+1)²−8(NIR−RED))]` | 自洽土壤调节 |
| GNDVI | `POST /api/v1/47_gndvi/run` | `(NIR − GREEN) / (NIR + GREEN)` | 绿光代替红光 |
| NDMI | `#30` 的 `ndmi.tif` | `(NIR − SWIR) / (NIR + SWIR)` | 植被水分（Gao 那条，本仓库不叫 NDWI） |
| NDWI | `#30` 的 `ndwi.tif` | `(GREEN − NIR) / (GREEN + NIR)` | **McFeeters 水体**，不是 Gao |
| MNDWI | `#30` 的 `mndwi.tif` | `(GREEN − SWIR) / (GREEN + SWIR)` | 抑建成区、提水体 |
| OSAVI | `POST /api/v1/48_osavi/run` | `(NIR − RED) / (NIR + RED + L)`，默认 `L=0.16` | 与 SAVI 同类，L 文献常用 0.16 |
| ARVI | `POST /api/v1/49_arvi/run` | `(NIR − RB)/(NIR + RB)`，`RB = RED − γ(BLUE − RED)` | 默认 `γ=1`；不能替代大气校正 |
| VARI | `POST /api/v1/50_vari/run` | `(GREEN − RED) / (GREEN + RED − BLUE)` | 可见光、无近红外 |
| LAI | `POST /api/v1/51_lai_index/run` | `max(3.618×EVI − 0.118, 0)` | 教学线性式，**不是** `#33` |
| NBR | `POST /api/v1/52_nbr/run` | `(NIR − SWIR) / (NIR + SWIR)` | 过火相对差异；教学 SWIR 约 1600 nm |
| SIPI | `POST /api/v1/53_sipi/run` | `(NIR − BLUE) / (NIR − RED)` | 色素比值；值域不必在 −1～1 |
| GCI | `POST /api/v1/54_gci/run` | `NIR/GREEN − 1` | 与 RECI 同型，分母是绿光 |
| NDSI | `POST /api/v1/55_ndsi/run` | `(GREEN − SWIR) / (GREEN + SWIR)` | 雪；与 MNDWI 同型不同用途 |

`#29` 一次跑出三个单波段文件：`evi.tif`、`savi.tif`、`msavi.tif`。  
`#30` 一次跑出三个单波段文件：`ndmi.tif`、`ndwi.tif`、`mndwi.tif`。无真 SWIR 时 NDMI/MNDWI/NBR/NDSI 没有物理意义。

## 不要和 01–45 的产线算法搞混

55 项清单见 [采集到算法-算法清单.md](./采集到算法-算法清单.md)。其中 **#1–#26** 是采集与预处理，**#31–#45** 是红边参数、反演、分类、解混、变化检测、地块统计等；**#46–#55** 才是为对齐这张 18 指数目录而补的独立指数。
