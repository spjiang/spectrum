# 常用植被指数 18 项对照

对照外部产品「常用植被指数」目录（NDVI、RECI、NDRE 等 **18** 个）与本仓库 **45** 项算法清单。

两套清单不是一回事：

- 外部这 18 个：几乎全是 **L3 光谱指数**（少数把 LAI 也放进指数菜单）
- 本仓库 45 项：从航线、定标、正射到分类、地块报表的 **整条产线**；指数只占其中一小段

统计（按「有没有做成同名指数产品」）：

| | 个数 | 指数 |
| --- | --- | --- |
| **已做** | **8** | NDVI、NDRE、MSAVI、NDWI、MNDWI、NDMI、SAVI、EVI |
| **没做** | **10** | RECI、GNDVI、OSAVI、ARVI、VARI、LAI（指数口径）、NBR、SIPI、GCI、NDSI |

已做的 8 个不是 8 个独立接口：NDVI、NDRE 各一项；EVI/SAVI/MSAVI 捆在 `#29`；NDMI/NDWI/MNDWI 捆在 `#30`。

## 已做的 8 个

控制台路径：`/algo/27_ndvi`、`/algo/28_ndre`、`/algo/29_evi_savi`、`/algo/30_ndmi_ndwi`。  
输入均要求 **反射率** GeoTIFF，波段索引从 0 起（教学数据默认：蓝 0、绿 1、红 2、近红外 3、红边 4、SWIR 5）。

| 简称 | 接口 | 公式（本仓库实现） | 说明 |
| --- | --- | --- | --- |
| NDVI | `POST /api/v1/27_ndvi/run` | `(NIR − RED) / (NIR + RED)` | 最常用绿度/长势 |
| NDRE | `POST /api/v1/28_ndre/run` | `(NIR − RE) / (NIR + RE)` | 密冠层、氮营养；须有真红边 |
| EVI | `#29` 输出第 1 波段 | `2.5(NIR−RED)/(NIR+6RED−7.5BLUE+1)` | 抑饱和、含蓝光项 |
| SAVI | `#29` 输出第 2 波段 | `(1+L)(NIR−RED)/(NIR+RED+L)`，默认 `L=0.5` | 稀疏植被压土壤 |
| MSAVI | `#29` 输出第 3 波段 | `0.5[2NIR+1−√((2NIR+1)²−8(NIR−RED))]` | 自洽土壤调节 |
| NDMI | `#30` 输出第 1 波段 | `(NIR − SWIR) / (NIR + SWIR)` | 植被水分（Gao 那条，本仓库不叫 NDWI） |
| NDWI | `#30` 输出第 2 波段 | `(GREEN − NIR) / (GREEN + NIR)` | **McFeeters 水体**，不是 Gao |
| MNDWI | `#30` 输出第 3 波段 | `(GREEN − SWIR) / (GREEN + SWIR)` | 抑建成区、提水体 |

`#29` 一次跑出三波段栈 `evi_savi_msavi.tif`（顺序 EVI、SAVI、MSAVI）。  
`#30` 一次跑出三波段栈 `ndmi_ndwi_mndwi.tif`（顺序 NDMI、NDWI、MNDWI）。无真 SWIR 时 NDMI/MNDWI 没有物理意义。

## 没做的 10 个

这些在外部指数菜单里常见，本仓库 **没有独立算法、也没有捆进 #27–#30**。

| 简称 | 通常公式 | 常见用途 | 备注 |
| --- | --- | --- | --- |
| RECI | `NIR/RE − 1` | 叶绿素、氮 | 需要红边 |
| GNDVI | `(NIR − GREEN) / (NIR + GREEN)` | 叶绿素，比 NDVI 多用绿光 | |
| OSAVI | `(NIR − RED) / (NIR + RED + 0.16)` | 土壤调节，L 固定 0.16 | 与 SAVI 同类，未单独做 |
| ARVI | `(NIR − RB) / (NIR + RB)`，`RB = RED − γ(BLUE − RED)` | 抗大气 | 常用 `γ=1` |
| VARI | `(GREEN − RED) / (GREEN + RED − BLUE)` | 可见光、无近红外时估覆盖 | |
| LAI | 厂商菜单里多为经验指数或查找表 | 叶面积 | 本仓库 `#33_physical_inversion` 用 PROSAIL 反演 LAI/Cab，**不是**这条指数 |
| NBR | `(NIR − SWIR) / (NIR + SWIR)` | 过火、过火严重度 | 形式接近 NDMI，波段与产品定义须按传感器核对 |
| SIPI | `(NIR − BLUE) / (NIR − RED)` | 色素、结构影响较小 | |
| GCI | `NIR/GREEN − 1` | 叶绿素 | 与 RECI 同型，分母是绿光 |
| NDSI | `(GREEN − SWIR) / (GREEN + SWIR)` | 雪 | 形式接近 MNDWI，阈值与用途不同 |

## 不要和 45 项搞混

45 项清单见 [采集到算法-算法清单.md](./采集到算法-算法清单.md)。其中 **#1–#26** 是采集与预处理，**#31–#45** 是红边参数、反演、分类、解混、变化检测、地块统计等，**都不是**这张 18 指数目录里的条目。

若要把外部 18 个指数做全，缺口就是上表 **没做的 10 个**；已做的 8 个只需在产品侧拆开展示（尤其是 #29、#30 的多波段栈），不必重复实现公式。
