# 当前服务简单介绍

本文对 `algorithm/source` 下的**高光谱算法 HTTP 服务**做简要说明：它是什么、解决什么问题、怎么用、目前做到哪一步。

---

## 一句话定位

**单进程 FastAPI 服务**，把业界 45 项高光谱相关算法能力收成统一 HTTP 入口：上传标准文件 → 返回 JSON（含专题图等产物路径）。

- 默认地址：`http://127.0.0.1:28800`
- 交互文档：`http://127.0.0.1:28800/docs`
- 代码目录：`algorithm/source/`

---

## 解决什么问题

| 角色 | 价值 |
|------|------|
| 业务 / 产品 | 不必自研遥感算法，用文件调用即可拿到指数图、分类结果、地块统计等 |
| 研发联调 | 统一契约，OpenAPI 可调试；清单编号与目录、接口一一对应 |
| 培训学习 | 对照 [采集到算法-算法清单](./采集到算法-算法清单.md) 理解 L0–L4 与各算法落点 |

---

## 架构（简化）

```text
调用方（curl / App / GIS）
        │
        ▼
  FastAPI 单服务  :28800
        │
        ├── GET  /api/v1/algorithms          算法列表
        └── /api/v1/{algorithm_id}/run|health
                └── algorithms/<id>/service.py
```

特点：

- **一个进程、一个端口**：运维与文档简单  
- **一算法一目录**：便于对照清单扩展  
- **统一 `/run` 契约**：输入输出形状一致  

更细的技术说明见：[source-http-api-设计说明.md](./source-http-api-设计说明.md)。

## 怎么调用

### 1. 启动

```bash
cd algorithm/source
source .venv/bin/activate   # 若已建虚拟环境
./scripts/start.sh
```

### 2. 查清单

```bash
curl -s http://127.0.0.1:28800/api/v1/algorithms
```

### 3. 跑算法

```bash
curl -X POST "http://127.0.0.1:28800/api/v1/27_ndvi/run" \
  -F "file=@algorithms/27_ndvi/testdata/input.tif" \
  -F 'params={"red_band":2,"nir_band":3}'
```

| 字段 | 说明 |
|------|------|
| `file` | 主输入（必填），如 GeoTIFF |
| `file2` | 第二输入（可选），如标签图、地块 GeoJSON |
| `params` | JSON 字符串参数 |

返回示例字段：`success`、`algorithm_id`、`implemented`、`data`（统计/指标）、`files`（产物绝对路径）。

完整 45 项 curl 见：[算法API测试清单.md](./算法API测试清单.md)。

## 文件格式

按业界交换习惯收发，而不是教学用 `.npy`：

| 方向 | 常用格式 |
|------|----------|
| 栅格入/出 | **GeoTIFF**（`.tif`）；可读 ENVI |
| 地块 / AOI | **GeoJSON** |
| 轨迹 / 光谱库 | **CSV** |
| 接口响应 | **JSON**（含 `files` 路径） |

详见：[业界文件格式介绍.md](./业界文件格式介绍.md)。

## 当前能力范围

### 已实现（可联调，教学级）

共 **9** 项（`implemented: true`）：

| 编号 | 能力 |
|------|------|
| 12 | 白板反射率定标（示意） |
| 20 | 坏波段剔除 |
| 21 | Savitzky–Golay 平滑 |
| 22 | 标准化 / 归一化 |
| 23 | PCA 降维 |
| 27 | NDVI |
| 28 | NDRE |
| 34 | SVM / 随机森林分类 |
| 45 | 地块汇总统计 |

### 骨架（接口已预留）

其余 **36** 项目录与 `POST /run` 已就绪，返回中会标明未完整实现；可按业务优先级补 `service.py`。

### 明确不在当前范围

- 生产级鉴权、排队、集群调度  
- 完整正射、大气校正、厂商相机 SDK 等处理中心能力  
- 替代专用遥感处理软件  

当前定位：**培训 + 联调 + 能力地图**；生产级算法可在同一目录结构上渐进补齐。

---

## 与业务链路的关系

```text
L0→L2  采集与预处理（多在处理中心） → 得到反射率正射立方体
L2→L3  本服务重点可演示：指数、清洗、分类等
L3→L4  本服务可演示：地块汇总 → 报表/告警形态
```

分类深度学习小模型主要在仓库其他目录（如 `hyper-spectral-small-modes`），可继续接到本服务的分类类接口上。
