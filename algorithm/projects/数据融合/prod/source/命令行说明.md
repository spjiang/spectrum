# 命令行说明

在 `prod/source` 下执行。Python 用仓库里的 `algorithm/source/.venv`。  
`--input` 的 `MAX_*` 目录只读，成果只写 `--out`，不要把 `--out` 指到输入目录里。

当前正在跑的 RGB 全量不要再开一条写同一个 `--out`。

```bash
PY="/Users/jiangshengping/wwwroot/shenzhen/spectrum/algorithm/source/.venv/bin/python"
SRC="/Users/jiangshengping/wwwroot/shenzhen/spectrum/algorithm/projects/数据融合/prod/source"
INPUT="/Users/jiangshengping/wwwroot/shenzhen/spectrum/algorithm/projects/数据融合/prod/docs/需求/测试正式数据/MAX_20251017/MAX_20251017_001"
CACHE="/Users/jiangshengping/wwwroot/shenzhen/spectrum/algorithm/projects/数据融合/prod/runs/full_MAX_20251017_001/cache/features"
```

也可以用包装脚本：`./run.sh --bands Color --out ../runs/xxx`（不写 `--out` 会自动落到 `../runs/manual_时间戳`）。

## 怎么看有没有跑完

```bash
# 有输出 = 进程还在
pgrep -lf ms_mosaic

# 密集匹配写完才会出现 DSM
ls -lh "/Users/jiangshengping/wwwroot/shenzhen/spectrum/algorithm/projects/数据融合/prod/runs/full_surface_rgb/拼图结果"

# 整趟最后才写比对报告；有这个文件且 pgrep 没输出，才算跑完
ls "/Users/jiangshengping/wwwroot/shenzhen/spectrum/algorithm/projects/数据融合/prod/runs/full_surface_rgb/比对报告.txt"

grep 未达标 "/Users/jiangshengping/wwwroot/shenzhen/spectrum/algorithm/projects/数据融合/prod/runs/full_surface_rgb/比对报告.txt"
```

全量把路径里的 `full_surface_rgb` 换成 `full_surface_all`。

成果在 `--out` 下：

| 路径 | 内容 |
| --- | --- |
| `拼图结果/DSM.tif` | DSM |
| `拼图结果/Orthomosaic_pix_surf_group0.tif` | RGB 正射 |
| `拼图结果/Orthomosaic_pix_surf_group1.tif` … `group7.tif` | 仅全量：7 个多光谱 |
| `质量报告.pdf` | 自研报告（署名单 `ms_mosaic`） |
| `比对报告.txt` | 对照商业 `拼图结果/` |

## 常用参数

| 参数 | 含义 |
| --- | --- |
| `--input` | 拍完后的 `MAX_*` 目录 |
| `--out` | 输出根目录 |
| `--bands` | 逗号分隔。省略 = 8 波段全量。例：`Color` |
| `--cache-dir` | 特征缓存，复用可跳过提取 |
| `--reuse-dsm` | 已有 `DSM.tif`，跳过密集匹配 |
| `--workers` | 密集匹配 / 正射进程数 |
| `--max-frames` | 只用前 N 个可用曝光（调试，不是交付） |

调试预览（不要当交付）：

```bash
./run.sh --max-frames 12 --bands Color --out ../runs/preview_rgb
```
