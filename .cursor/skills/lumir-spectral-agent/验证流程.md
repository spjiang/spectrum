# LUMIR Skill 手动验证流程（OpenClaw）

本流程给你逐项勾选。机器已跑过离线自检；你在 OpenClaw 里按同样步骤复核。

## 0. 分发包

- 文件：`.cursor/skills/lumir-spectral-agent-openclaw.zip`
- 内容：`lumir-spectral-agent/`（含 `SKILL.md`、`scripts/`、`knowledge_base/`）
- **不含** `.env`、`config.yaml`、`Papers/`、`vendor/`、历史 `runs/*.json`

完整文献溯源包：`python3 scripts/pack_for_openclaw.py --full`

---

## 1. 本机准备

```bash
cd lumir-spectral-agent
python3 -m pip install -r requirements.txt
```

准备用户光谱：上传到 OpenClaw，或记下本机绝对路径 `SPECTRA`（回归另备 `LABELS`）。

完整 E2E：

```bash
cp .env.example .env
# 填写 LUMIR_API_KEY（不要发给任何人）
cp config.example.yaml config.yaml
```

---

## 2. 导入 OpenClaw

OpenClaw CLI **2026.7.1-2** 需要 **Node 24+**。现有 `~/.openclaw/openclaw.json`（2026.4.21）与新 CLI 不兼容，**不要随意**对主配置执行 `doctor --fix`。请用隔离 profile：

```bash
export PATH="/opt/homebrew/opt/node@24/bin:$PATH"
openclaw --profile lumir-test skills install ./lumir-spectral-agent --as lumir-spectral-agent --force
openclaw --profile lumir-test skills list | grep lumir
```

确认 `lumir-spectral-agent` 为 ready。网关：`http://127.0.0.1:19011/`（profile `lumir-test`）。

---

## 3. 手动用例

打开新会话，然后逐条粘贴 [tests/openclaw_cases.md](tests/openclaw_cases.md) 中的「用户输入」，把 `<SPECTRA>` 换成实际上传路径。

| 步骤 | 用例 | 你要核对的屏幕结果 | 勾选 |
|------|------|--------------------|------|
| 3.1 | TC-01 离线 | 有 `runs/offline_*.json`；有 accuracy；有 data_path；无 Key | ☐ |
| 3.2 | 打开该 json | 含 `entity/retrieve/methods/features/infer` | ☐ |
| 3.3 | TC-02 回归 | 有 R²；任务为 regression | ☐ |
| 3.4 | TC-03 禁止喂原始光谱 | Agent **拒绝**贴 npy，改为跑脚本 | ☐ |
| 3.5 | TC-04 禁止 vendor | 未执行 `vendor/**/*.py` | ☐ |
| 3.6 | TC-06 无数据 | **拒绝**用内置样本，要求上传或路径 | ☐ |
| 3.7 | TC-05 E2E（有 Key） | `runs/e2e_*.json` 五段齐全 | ☐ |

---

## 4. 命令行对照

在 Skill 根目录（路径换成你的文件）：

```bash
python3 scripts/verify_skill_bundle.py
python3 scripts/run_offline.py --data "$SPECTRA" --task classification --object "<材料>" --offline
python3 tests/test_job_input.py
```

期望：`全部验收通过` / `全部输入契约通过`；离线作业退出码 0。

有 Key 时：

```bash
python3 scripts/run_e2e.py --data "$SPECTRA" --task classification --object "<材料>"
```

期望：退出码 0，且最新 `runs/e2e_*.json` 含 `steps.infer.metrics` 与 `data_path`。

---

## 5. 失败时怎么看

| 现象 | 先查 |
|------|------|
| 缺少光谱数据 | 未传 `--data`；或 OpenClaw 未上传文件 |
| `找不到知识库` | zip 根目录是否有 `knowledge_base/` |
| `No module named rank_bm25` | 未安装 `requirements.txt` |
| 离线成功但 E2E 退出 | `.env` 是否有 `LUMIR_API_KEY` |
| 列表没有该 Skill | `SKILL.md` 是否在安装目录根 |
