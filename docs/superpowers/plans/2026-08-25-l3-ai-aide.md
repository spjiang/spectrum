# L3 AI 参谋 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 独立站点 `ai-web/` 一页跑通密植水稻补氮演示：选型 NDRE 主跑、NDVI 对照、解释与带边界建议。

**Architecture:** 算法服务新增 `POST /api/v1/l3-aide/run`；场景表是选型权威；27/28 用 `28_ndre` testdata 同景计算；叙述器默认模板，可选 LLM 润色且不得改计划。`ai-web` 只做四段展示并代理到 28800。

**Tech Stack:** Python 3.10、FastAPI、unittest、Vue 3、Vite 6、TypeScript。

- 原始栅格、立方体、PNG 字节不得进入 LLM 提示词。
- `advice.isPrescription` 恒为 false；建议必须含「不是处方」。
- 未经用户明确要求不得 `git commit` / `git push`。
- 前端目录必须是仓库根下 `ai-web/`，端口 5174。
