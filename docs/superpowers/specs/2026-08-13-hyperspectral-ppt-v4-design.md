# 高光谱算法体系 v4 PPT 设计

## 目标

在不改变 v3 的 62 页总体结构与讲解顺序的前提下，统一视觉系统，修复标题和排版问题，并将内容改写为专业、准确、适合领导汇报与技术培训的表达。

## 输入与输出

- 输入：`algorithm/docs/高光谱算法体系-v3.pptx`
- 内容依据：
  - `algorithm/docs/采集到算法-算法清单.md`
  - `algorithm/docs/当前服务简单介绍.md`
  - `algorithm/docs/算法API测试清单.md`
- 输出：`algorithm/docs/高光谱算法体系-v4.pptx`
- v3 保留，不覆盖。

## 范围

- 保留 62 页，不增删主要章节。
- 允许调整单页版式、图形、文本结构和专业表述。
- 修复残缺标题，例如“05”“06”“#11”“39”等。
- 45 项算法页统一信息结构。
- 明确区分“可运行”和“骨架”，不得把接口 HTTP 200 描述为核心算法已实现。

## 视觉系统

### 风格

政企科技蓝：正式、清晰、可投屏、可打印。

### 配色

- 主色：深蓝，用于标题、章节和关键流程。
- 辅色：科技青，用于连线、强调和可运行状态。
- 风险色：橙色，仅用于限制、风险和骨架状态。
- 背景：白色或极浅蓝灰。
- 正文：深灰黑，避免大面积纯黑。

### 字体与字号

- 中文：统一使用 `Noto Sans SC`，缺失时回退 `PingFang SC`。
- 英文与数字：统一使用 `Inter`。
- 页面标题：28–32 pt。
- 二级标题：20–22 pt。
- 正文：16–18 pt。
- 标签与图注：11–13 pt。
- 单页字号层级不超过 4 级。

### 固定元素

- 左上：章节/层级标识。
- 右下：页码。
- 底部：简洁页脚线或文档名称。
- 状态标签：
  - 可运行：青绿色标签。
  - 骨架：橙色标签，文字明确为“接口已预留，核心算法待实现”。

## 页面模板

1. 封面：主标题、副标题、版本、日期。
2. 目录：三部分结构，突出当前章节。
3. 章节页：大编号、章节名称、章节目标。
4. 架构页：流程图/分层图优先，减少大段文字。
5. 总览页：分层表格、能力数量和状态统计。
6. 算法页：统一五区结构。
7. 服务页：统一接口、输入输出、调用步骤、状态边界。
8. 总结页：能力、现状、建设路径和下一步。

## 45 项算法页统一结构

每页固定包含：

1. 算法编号、中文名称、所属层级、algorithm_id。
2. 解决问题：一句话说明为什么需要。
3. 技术原理：2–3 句专业但非论文式描述。
4. 输入与输出：采用清晰的左右结构。
5. 业务价值：说明对质量、效率、成本或决策的贡献。
6. 当前状态：可运行或骨架。
7. 工程提示：关键参数、依赖条件或使用限制。

## 内容口径

- 45 项算法名称、层级、输入输出以算法清单为准。
- 状态以 API 测试清单最新记录为准：12 项可运行、33 项骨架。
- 当前服务说明中旧的 11/34 口径不再使用。
- 避免“全面支持”“生产可用”等无证据表述。
- 用“当前示例实现”“教学级可运行”“生产化仍需……”说明能力边界。

## 质量检查

- 62 页数量不变。
- 45 个算法编号连续且标题完整。
- 页面标题、字体、页码、状态标签一致。
- 正文无溢出、遮挡、过小字号和孤立单字。
- 可运行/骨架统计为 12/33。
- 输出可由 PowerPoint/WPS 正常打开。
- 生成至少 6 张关键页面预览图用于审阅：封面、架构、总览、算法页、服务页、总结页。
